# 🌡️ Temperature Converter App

A simple and user-friendly Temperature Converter application developed using HTML, CSS, and JavaScript. It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

## 🚀 Features

- 🌡️ Convert Celsius to Fahrenheit
- ❄️ Convert Fahrenheit to Celsius
- 🔥 Convert Celsius to Kelvin
- 🌍 Convert Fahrenheit to Kelvin
- 🔄 Convert Kelvin to Celsius
- 🔢 Instant temperature conversion
- ⚠️ Input validation for incorrect values
- 📱 Responsive design
- 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter the temperature value.

5. Select the input and output temperature units.

6. Click the Convert button to get the result.
